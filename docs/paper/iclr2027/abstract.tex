\begin{abstract}
Adapting a large pre-trained vision model to a new task from only a handful of labels is now routine, yet the resulting predictions lack a calibrated measure of uncertainty. Conformal prediction (CP) provides such a measure by turning any scoring function into prediction sets with distribution-free, finite-sample guarantees. Applying CP in this setting, however, poses a practical challenge: standard split conformal methods require fitting a $K$-way classifier before calibration, forcing a scarce label budget to be divided between model training and conformal inference. self-supervised foundation models offer a way around this trade-off by providing embeddings from which each class can be represented by the mean of its labeled examples. We propose \emph{FRCP} (Feature-Refined Full Conformal Prediction), which applies full (transductive) conformal prediction with a training-free prototype score directly to these embeddings, allowing the entire labeled sample to be used for conformal inference. While this resolves the label-allocation trade-off, prediction-set efficiency still depends on the representation. FRCP therefore further refines it using truncation, whitening, and smoothing, all fitted solely on an unlabeled image pool. The same refinement map is applied to calibration and test points, preserving conformal coverage while improving efficiency. Across image-classification benchmarks and label budgets, our method gives the smallest sets in every comparison at the scarcest budgets.
\end{abstract}
